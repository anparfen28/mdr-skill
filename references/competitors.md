# Конкуренты Mindbox — если регистрант из такой компании, НЕ общаемся

**Правило (Анна, 17.07):** если **сама компания регистранта** — один из martech/CDP/ESP/loyalty-вендоров ниже (т.е. человек работает В этой компании, напр. `@edna.ru`, `@sendpulse.com`), это **конкурент → нецелевой, «конкурент, не общаемся»**. Дисквалификатор уровня компании (как незаконный бизнес/агентство).

⚠️ **Не путать с колонкой «Конкурент / на чём сидит» (K).** Там — инструмент, которым пользуется ЦЕЛЕВАЯ компания (напр. магазин сидит на Criteo). Это, наоборот, сигнал ЦЕЛЕВОГО лида (можем заместить их стек). Дисквалифицирует только когда компания = сам вендор.
