Этот файл — **снапшот**. Перед заходом ищи кейс под модель клиента на сайте.
- ⚠️ `mindbox.ru/journal/cases/` **редиректит** на `/journal/`. Настоящий индекс фильтров: **`https://mindbox.ru/journal/tag/`** (все теги со счётчиками).
- **URL-паттерны** (только path, query-параметров нет): лента по фильтру `/journal/tag/<slug>/` · статья-кейс `/journal/cases/<slug>/` · экспертиза `/journal/experts/<slug>/`.
- **4 оси фильтров:** Индустрия (24) · **Бизнес-модель (28)** · Продукт-модуль (20) · Задача/механика (30). Оси «размер бизнеса» НЕТ.
- **Алгоритм:** `/journal/tag/` → выбрать **бизнес-модель** (точнее, чем индустрия: `omnikanalnyj-magazin` 165, `onlajn-magazin` 179, `agregator-marketplejs` 38, `shkola-obrazovatelnyj-servis` 36, `restoran` 21, `bukmeker` 2) → пересечь с **механикой** (`reaktivaciya` 87, `mehaniki-programmy-loyalnosti` 93, `brosennaya-korzina` 115, `segmentaciya` 300, `ltv` 48) → редкая модель → поиск в шапке журнала с фасетом **«Кейсы»** (серый счётчик = кейсов нет).
- ⚠️ Каталог рендерится JS → **нужен браузер**, WebFetch отдаёт только шаблон.
- Цифры в лентах — из заголовков карточек; если цифра идёт в КП, открыть статью и сверить с телом.

Источник: объединено из наработок Тагира (`mdr-mindbox`) и памяти Андрея (`project_mindbox_case_library`). Снапшот июль 2026 — **неполный и стареет**. Под конкретного лида проверяй свежее на `mindbox.ru/journal/cases/` или `mindbox.ru/clients/{отрасль}&all/`; если нашёл кейс точнее под отрасль — бери его.

**Правило:** в заходе всегда кейс из той же или максимально близкой отрасли, что и лид, и **с конкретной цифрой результата** (выручка, конверсия, CLTV, retention) — не общее описание платформы. Цифра — то, что цепляет.

## ⚠️ Проверенные пробелы каталога (18.07, прогон по ~30 тегам / 404 кейсам)
Это не «не нашлось», а проверено регуляркой по лентам — экономит время и защищает от натяжек:
- **Удержание/продление ПОДПИСКИ в образовании — кейса НЕТ.** У Mindbox онлайн-школы в кейсах = продажа курса, а не подписочная модель. Ближайшее **по механике периодического платежа**: **MPSTATS** +10% выручки (B2B-подписка через рассылки) · **Jivo** +35,5% конверсии welcome во free→paid · **Okko** retention +5 п.п./год (подписочный кинотеатр) · **Сетка** +2,8 п.п. к retention новичков.
- **Салоны красоты — кейса НЕТ.** Тег «Фото, химчистка, салон красоты» = 2 кейса, оба про фотопечать (Print Bar, netPrint). Замена по механике «услуга + запись + лояльность»: **XFIT** (доп. услуги 35→40%) · **Aravia** (+11% ARPU).
- **Недвижимость / доставка цветов — много карточек БЕЗ цифры в заголовке** (ПИК, Urban Group, Флорист.ру годятся только как «имя для доверия»). Единственный застройщик с реальной метрикой — **А101 (+20% обращений)**.

## Маппинг боль → модуль → тип кейса
- Боль **удержание/повторные покупки** → рассылки + CDP → кейс с ростом CRM-выручки/частоты
- Боль **лояльность** (бонусы/приложение) → модуль Лояльность → кейс с ростом проникновения ПЛ / retention
- Боль **брошенные корзины / конверсия сайта** → персонализация + ML → кейс с ростом конверсии
- Боль **реактивация базы** → триггеры/RFM → кейс с ростом доли email в выручке
