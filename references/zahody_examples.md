# КАРКАС АНДРЕЯ — e-mail на основе анализа САЙТА (второй рабочий стиль)

Заходы Тагира выше — мессенджерные, «после ивента», с кейсами по нише. **Каркас Андрея — другой рабочий стиль:** e-mail, где зацепка не ивент и не кейс, а **2–3 конкретных наблюдения по сайту лида** («кто X → сделать Y»), и мягкий выход на разговор через вопрос о задачах. Кейс тут **опционален** — если наблюдения по сайту уже конкретны, кейс можно опустить, чтобы не раздувать. По образцу реального письма Андрея:

> Добрый день!
>
> Меня зовут {имя MDR}, я из Mindbox. {Повод: видел сайт / регистрировались на ивент / оставили заявку — коротко, без воды}. Решил написать.
>
> {Абзац-наблюдение: 2–3 конкретных сегмента их клиентов/данных в формате «кто X — сделать Y», строго из того, что реально нашли на сайте. Не абстрактная польза платформы, а прямая привязка к их модели бизнеса.}
>
> Расскажите, пожалуйста, есть ли у вас какие-то задачи в автоматизации маркетинга на данный момент?
>
> Если сойдёмся по задачам — хотели бы пригласить на короткую встречу: покажем механики под вашу модель, погенерируем гипотезы.
>
> {Имя MDR}, Mindbox

**Когда какой стиль:** тёплый лид **после ивента/контента** с понятной нишей → стиль Тагира (повод-ивент + кейс с цифрой). Лид **от заявки/сайта** без яркого ивент-контекста, или когда сильны наблюдения по сайту → каркас Андрея (наблюдения + вопрос о задачах). Оба — короткие, по-русски, без эмодзи, CTA = встреча.
